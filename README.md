# どんぐりと山猫

宮沢賢治『どんぐりと山猫』を、ルビ付きで読めるオフライン対応PWAです。

## 主な機能

- 青空文庫の新字新仮名版を収録
- オフライン閲覧
- 読書位置の自動保存
- 文字サイズ・行間・背景色の調整
- 横書き／縦書き、ルビ表示の切り替え
- ホーム画面へのインストール

## ローカルで読む

Service WorkerはHTTP環境で動作するため、リポジトリのルートで簡易サーバーを起動します。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## 検証

```sh
npm test
npm run check
```
